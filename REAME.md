# ALU Regex Data Extraction Project

This project is set to extract specific data types from a dataset using Regular Expressions. The data types that will be extracted are:

- Email addresses
- URLs
- Phone numbers
- Currency amounts

## Setup Instructions

1. Clone this repository: https://github.com/Adossi-design/alu_regex-data-extraction-Adossi_Fred_William.git
2. Make sure that Node.js is install on your computer
3. 3. Cd the repository name
4. Run the script by typing node main.js
